# Catalyst Preset Picker – upgrade list

Work through these one prompt at a time. Tick them off as they land.

- [x] 1. **Quick fix buttons** – on each sound: "Too bright", "Too dark", "More gain", "Less gain", "More sustain", "Too quiet". One click nudges the knobs and sends the sound to the amp again. You keep the result as your own version, so the stock sound is never lost.
- [ ] 2. **Setlist / gig mode** – make an ordered list of songs, then use big Next / Previous buttons (or the arrow keys and space bar) to load each one onto the amp. Lists are saved.
- [ ] 3. **Send whole bank to amp** – the bank builder can already download a bank. This adds a button that saves every sound into the slots you choose, then confirms each slot. It still only writes to slots you name.
- [ ] 4. **Song details** – a tuning badge (Eb for SRV and Hendrix), which pickup to use on the Cort, and the song's key. Filter by "standard tuning only".
- [ ] 5. **A/B compare** – pick two sounds, then flip between them on the amp with one key.
- [ ] 6. **Back up the amp first** – before any save, read what's in the slot and keep a copy so you can undo. Needs checking whether Catalyst Edit allows this.
- [ ] 7. **More classical and fingerstyle** – sounds for specific pieces and players (Tárrega, Bach lute suites, Segovia-style, Tommy Emmanuel), to match the song sets.
